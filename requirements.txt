# Every third-party import in this project must be listed here. CI installs ONLY
# what is in this file, so anything missing works locally -- where it is already
# installed -- and fails in the Action.
#
# Not hypothetical: anthropic and python-dotenv were both missing. Because
# pipeline.py imports classifier lazily, inside main() and after the "nothing new
# to classify" early return, the Action passed every day that brought no new
# items and failed the first day one appeared. Two days of green runs had never
# executed the import.
feedparser>=6.0.10
anthropic>=0.40.0
python-dotenv>=1.0.0
# fetcher.py uses certifi's CA bundle to complete the TX Dept of Banking cert
# chain. Usually present transitively (via anthropic/httpx); pinned so CI never
# depends on that by accident.
certifi>=2024.2.2
# dashboard.py's zoneinfo lookup ("America/New_York" for the Updated stamp)
# needs an IANA tz database. The Ubuntu Action runner has one system-wide, but
# pinning this package means the lookup doesn't depend on that being true --
# same reasoning as certifi above.
tzdata>=2024.1
